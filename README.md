# Exercícios de Lógica de Programação e Algoritmos

Exercícios de fixação (não avaliativos) da disciplina de Lógica de Programação e
Algoritmos, do curso de Análise e Desenvolvimento de Sistemas (ADS). Resolvidos
por conta própria como prática, cobrindo condicionais, laços de repetição,
funções e tratamento de erros em Python.

## Exercícios

| Arquivo | Conteúdo praticado |
|---|---|
| `exercicio_01_desconto_vendas.py` | Estruturas condicionais `if`/`elif`/`else`, cálculo de desconto por faixas |
| `exercicio_02_loja_acai.py` | Laços `while`, `break`, `continue`, validação de entrada, condicionais aninhadas |
| `exercicio_03_copiadora.py` | Funções com `return`, `try`/`except`, validação de entrada numérica |

## Como executar

Cada arquivo é independente. Basta rodar com Python 3:

```bash
python exercicio_01_desconto_vendas.py
```

Exercícios propostos pelo Prof. Me. Bruno Kostiuk, sem gabarito oficial —
